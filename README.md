# JavaScript ECS Version

A beginner-friendly JavaScript project demonstrating **ECMAScript 6 (ES6)** concepts and the **Entity Component System (ECS)** programming approach.

## 📌 About

## 🎯 Purpose

The main purpose of this project is to strengthen JavaScript fundamentals and explore the **Entity Component System (ECS)** concept, which is commonly associated with game development and simulations.

ECS generally separates:

* **Entities** — individual objects or identifiers
* **Components** — data associated with entities
* **Systems** — logic that operates on entities and their components

This separation can make complex applications easier to organize and extend.
